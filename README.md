# 카카오톡/디스코드 채팅방 분석 및 자동완성 키보드 앱 프로젝트

## 1. 개요

이 프로젝트는 **인공지능(AI)**을 활용하여 사용자가 내보낸 **카카오톡 또는 디스코드 채팅방 데이터**를 분석하고, 그 결과를 바탕으로 개인화된 **자동완성 키보드** 기능을 제공하는 것을 목표로 합니다.

- **채팅방 분석**: AI 모델을 통해 채팅방의 분위기(긍정적/부정적), 자주 사용되는 단어, 유행어, 문체 등을 파악합니다.
- **자동완성 키보드**: 분석된 데이터를 기반으로, 사용자가 설정한 **페르소나**나 **문체**에 맞춰 문장을 자동 완성하거나 추천하는 기능을 구현합니다. 

---

## 2. 주요 기능

### 2.1. 채팅방 분석 기능

사용자가 제공한 채팅방 파일을 분석하여 다음과 같은 정보를 제공합니다.

- **분위기 분석**: 채팅방의 전반적인 **긍/부정 분위기**를 판단하고, 감정 변화 추이를 시각화합니다.
- **핵심 키워드 추출**: 채팅방에서 가장 많이 사용되는 **단어**와 **유행어**를 분석하여 제시합니다.
- **관계 분석**: 대화 참여자 간의 **상호작용 빈도**와 **주요 대화 주제**를 분석합니다. 
- **문체 분석**: 각 참여자의 **고유한 문체**와 **언어 습관**을 학습합니다.

### 2.2. AI 기반 자동완성 키보드

분석된 데이터를 활용하여 사용자에게 최적화된 키보드 경험을 제공합니다.

- **페르소나 설정**: 사용자가 원하는 **말투(친근한, 격식 있는, 재미있는 등)**를 설정하면, 해당 페르소나에 맞는 자동완성 문구를 추천합니다.
- **문맥 기반 완성**: 사용자가 입력하는 문맥을 파악하여 다음에 올 단어나 문장을 예측하고 제안합니다. 
- **이모티콘 및 특수문자 추천**: 대화 내용과 분위기에 맞는 **이모티콘**이나 **특수문자**를 자동으로 추천합니다.
