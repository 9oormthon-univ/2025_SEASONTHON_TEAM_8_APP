## 1. 개요

이 프로젝트는 **인공지능(AI)**을 활용하여 사용자가 내보낸 **카카오톡 또는 디스코드 채팅방 데이터**를 분석하고, 그 결과를 바탕으로 개인화된 **자동완성 키보드** 기능을 제공하는 것을 목표로 합니다.

- **채팅방 분석**: AI 모델을 통해 채팅방의 분위기(긍정적/부정적), 자주 사용되는 단어, 유행어, 문체 등을 파악합니다.
- **자동완성 키보드**: 분석된 데이터를 기반으로, 사용자가 설정한 **페르소나**나 **문체**에 맞춰 문장을 자동 완성하거나 추천하는 기능을 구현합니다. 

---

## 2. 주요 기능

### 2.1. 채팅방 분석 기능

사용자가 제공한 채팅방 파일을 분석하여 다음과 같은 정보를 제공합니다.

- **분위기 분석**: 채팅방의 전반적인 **긍/부정 분위기**를 판단하고, 감정 변화 추이를 시각화합니다.
- **핵심 키워드 추출**: 채팅방에서 가장 많이 사용되는 **단어**와 **유행어**를 분석하여 제시합니다.
- **관계 분석**: 대화 참여자 간의 **상호작용 빈도**와 **주요 대화 주제**를 분석합니다. 
- **문체 분석**: 각 참여자의 **고유한 문체**와 **언어 습관**을 학습합니다.

### 2.2. AI 기반 자동완성 키보드

---

- **페르소나 설정**: 사용자가 원하는 **말투(친근한, 격식 있는, 재미있는 등)**를 설정하면, 해당 페르소나에 맞는 자동완성 문구를 추천합니다.
- **문맥 기반 완성**: 사용자가 입력하는 문맥을 파악하여 다음에 올 단어나 문장을 예측하고 제안합니다. 
- **이모티콘 및 특수문자 추천**: 대화 내용과 분위기에 맞는 **이모티콘**이나 **특수문자**를 자동으로 추천합니다.

### 2.3. 고급 AI 기능

---

#### 🔄 **리라이팅 (문체 변환)**
- **공손체**: 격식 있고 정중한 말투로 변환
- **친근체**: 편안하고 친근한 말투로 변환  
- **단답체**: 간결하고 명확한 말투로 변환
- **격식체**: 비즈니스 상황에 적합한 말투로 변환
- **반말체**: 친구나 동료에게 사용하는 말투로 변환

#### ✍️ **맞춤법 검사**
- **실시간 검사**: 작성 중인 텍스트의 맞춤법을 즉시 검사
- **오류 표시**: 맞춤법 오류를 명확하게 표시하고 수정 제안
- **일괄 수정**: 확인 버튼으로 모든 오류를 한 번에 수정

#### 📅 **일정 추가**
- **자동 추출**: 텍스트에서 장소, 날짜, 시간, 메모 정보를 자동으로 추출
- **스마트 인식**: "내일 3시에 카페에서 만나!" 같은 자연어를 자동으로 파싱
- **편집 가능**: 추출된 정보를 사용자가 직접 수정하여 정확성 확보
- **캘린더 연동**: 완성된 일정을 캘린더에 자동으로 등록

## 🎯 사용법

### AI 기능 사용하기

1. **키보드 활성화**: 텍스트 입력 필드에서 키보드를 활성화합니다.

2. **AI 기능 버튼 선택**:
   - **리라이팅**: 문체 변환이 필요한 텍스트를 선택하고 버튼을 누릅니다.
   - **맞춤법**: 작성 중인 텍스트의 맞춤법을 검사하려면 버튼을 누릅니다.
   - **일정추가**: 일정 정보가 포함된 텍스트에서 버튼을 누릅니다.

3. **옵션 선택 및 확인**:
   - 리라이팅: 원하는 문체를 선택하면 자동으로 변환됩니다.
   - 맞춤법: 검사 결과를 확인하고 수정 버튼을 눌러 오류를 수정합니다.
   - 일정추가: 추출된 정보를 확인하고 필요시 수정한 후 등록합니다.

### 예시

```
입력: "내일 3시에 카페에서 만나!"
→ 일정추가 버튼 클릭
→ 자동 추출: 장소(카페), 날짜(내일), 시간(15:00), 메모(친구와 만남)
→ 확인 후 캘린더에 등록
```
